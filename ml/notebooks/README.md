# Jupyter notebooks

Suggested independent workstreams:
- `01_data_exploration.ipynb`: dataset exploration and preprocessing experiments.
- `02_parking_detection.ipynb`: free/occupied parking-slot detection.
- `03_vehicle_classification.ipynb`: vehicle-type classification.
- `04_parking_prediction.ipynb`: parking-demand forecasting.

Create notebooks here and commit lightweight notebooks and result figures. Keep large raw datasets out of Git; document download instructions in `ml/data/README.md`.
